# cookie ストア 要件定義書

## 1. 目的

API・ワーカー・ログイン用ブラウザの3アプリが共有する、cookie ファイルとプロファイル定義の契約を定める。ユーザ名とパスワードを渡さず保存せずに、ログイン済みセッションを yt-dlp へ安全に受け渡せるようにする。

## 2. スコープ

### 2.1 対象

- cookie ファイルの形式、配置、権限、更新方法。
- プロファイル名の検証と、状態（未保存・有効・失効）の判定。
- プリセットと履歴によるプロファイル定義、および URL からの自動選択。
- yt-dlp への cookie の受け渡しと書き戻し。
- 再ログイン用 URL の組み立て。

### 2.2 対象外

- ブラウザでのログイン操作。
- ジョブの実行とキューの管理。
- ログイン要求の HTTP 応答の形式。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: cookie はプロファイル名ごとの Netscape 形式ファイルとして保存し、権限 600 の一時ファイル経由で置き換える。
- FR-2: プロファイル名は、英数字・ハイフン・アンダースコアの 1〜64 文字に限る。
- FR-3: プロファイルの状態は、ファイルが無ければ未保存、失効記録より新しいファイルがあるか記録が無ければ有効、それ以外は失効とする。
- FR-4: 失効の記録は Redis に持ち、cookie ファイルが置き直されれば自動で有効へ戻る。
- FR-5: yt-dlp には cookie の一時コピーを渡し、内容が変わっていれば、実行の失敗時も含めて元のファイルへ書き戻す。
- FR-6: ユーザ指定のオプションに cookie や認証情報の指定があれば拒否し、エラー文には値を含めない。
- FR-7: ログへ出すコマンドでは、cookie ファイルの指定値を伏せる。
- FR-8: プロファイル一覧は名前・状態・更新時刻・再ログイン用 URL を返し、cookie の中身を含めない。
- FR-9: プロファイル定義は同梱のプリセットと cookie ストア内の履歴からなり、プリセットを先に照合し、壊れた履歴は無視する。
- FR-10: URL のホストが定義の対象ドメインと同じか配下であれば、そのプロファイルを自動選択する。
- FR-11: yt-dlp の出力がログイン要求かどうかを、エラー文の部分一致で判定する。
- FR-12: 再ログイン用 URL は、操作 URL の設定があるときに限り、プロファイル名と開始 URL を付けて組み立てる。

## 5. 非機能要件

- NFR-1: 3アプリに置く cookie 処理の複製は、差分 0 行で一致させる。
- NFR-2: cookie の値は、ログ・Redis・API 応答のいずれにも 0 件出力する。

## 6. 受け入れ条件

- AC-1 (FR-1): 保存した cookie ファイルの権限は 600 で、置き換えの途中の内容を読み手が観測しない。
- AC-2 (FR-2): 英数字・ハイフン・アンダースコア以外を含む名前、65 文字以上の名前は拒否される。
- AC-3 (FR-3): ファイルが無いと未保存、失効記録より新しいファイルがあると有効、それ以外は失効になる。
- AC-4 (FR-4): 失効中のプロファイルの cookie ファイルを置き直すと、有効に戻る。
- AC-5 (FR-5): 実行が失敗しても、yt-dlp が更新した cookie が元のファイルへ書き戻され、一時ファイルは残らない。
- AC-6 (FR-5): 内容が変わらなかった場合は、元のファイルの更新時刻が変わらない。
- AC-7 (FR-6): cookie と認証情報を指定するオプションは、長い形・短い形・値連結形のいずれも拒否され、値はエラー文に含まれない。
- AC-8 (FR-7): ログ用に整形したコマンドでは、cookie ファイルの指定値が伏せられる。
- AC-9 (FR-8): プロファイル一覧の各行に、cookie の中身が含まれない。
- AC-10 (FR-9): プリセットと同名の履歴は一覧に現れず、プリセットが先に並ぶ。
- AC-11 (FR-10): 対象ドメインの配下のホストの URL は、対応するプロファイルに解決される。
- AC-12 (FR-9): 壊れた履歴ファイルがあっても、プリセットの解決は動作する。
- AC-13 (FR-11): ログイン要求の文言は真、無関係なエラー文は偽と判定される。
- AC-14 (FR-12): 操作 URL が未設定なら空、設定があればプロファイル名と開始 URL が付いた URL になる。
- AC-15 (NFR-1): API・ワーカー・ブラウザ用の cookie 処理ファイルの内容が一致する。
- AC-16 (NFR-2): エラー文とログ用コマンドに、cookie の値が含まれない。
