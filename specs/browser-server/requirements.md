# ログイン用ブラウザ 要件定義書

## 1. 目的

利用者が、パソコンでもスマートフォンでも、自分のブラウザからサーバ上のブラウザを操作してログインし、その cookie をプロファイルとして保存できるようにする。ユーザ名とパスワードをシステムに渡さず、サイトごとの実装も要らない。

## 2. スコープ

### 2.1 対象

- ログイン用ブラウザの起動、画面配信、入力の受け渡し、終了。
- cookie の回収と、対象サイトのものだけの保存。
- プロファイルの選択、新しいサイトの追加、履歴の削除。
- 再ログイン用 URL から開いたときの入力済み表示。

### 2.2 対象外

- ログイン操作の自動化と、CAPTCHA の自動突破。
- ログイン完了の自動検知。
- 外部へ公開するための認証。

## 3. 前提

- 前提: cookie-store — 保存形式、プロファイル定義、履歴を共有するため

## 4. 機能要件

- FR-1: 利用者は自分のブラウザで操作ページを開き、クライアントソフトなしでサーバ上のブラウザを操作してログインできる。
- FR-2: ログイン操作は同時に1件とし、開始の要求を受けてからブラウザを起動し、待機中は起動しない。
- FR-3: 保存の操作で、プロファイルの対象ドメインの cookie だけを Netscape 形式で cookie ストアへ保存し、保存件数を返す。
- FR-4: 対象の cookie が0件のときは保存せず、ブラウザを残してログイン操作を続けられる。
- FR-5: 保存・取り消し・時間切れ・内部エラーのいずれでも、ブラウザとブラウザのプロファイルを破棄する。
- FR-6: ブラウザの画面を端末の表示領域の大きさで配信し、タッチ・マウス・キー・文字入力・戻る・再読み込みを送れる。
- FR-7: 新しいタブとポップアップへ表示が追従し、表示中のタブが閉じたときは残りのタブへ戻る。
- FR-8: ブラウザはヘッドありで起動し、スマートフォン操作時だけ起動フラグでユーザーエージェントを変え、タイムゾーンと言語を設定値に合わせる。
- FR-9: 画面配信用のポート以外を LAN へ公開せず、ブラウザの制御ポートはループバックに限る。
- FR-10: プロファイルはプリセットと履歴から選べ、新しいサイトは名前と開始 URL で使え、保存に成功したら履歴へ加える。
- FR-11: 履歴の削除は cookie も消し、プリセットとログイン操作中のプロファイルの削除は拒否する。
- FR-12: 操作ページは、クエリのプロファイル名と開始 URL を選択と入力欄へ反映し、各プロファイルの保存状況を表示する。

## 5. 非機能要件

- NFR-1: ログイン操作は、開始から既定 900 秒で自動終了する。
- NFR-2: cookie の値は、ログ・操作ページ・API 応答のいずれにも 0 件出力する。
- NFR-3: 待機中に存在するブラウザ関連のプロセスは 0 個とする。

## 6. 受け入れ条件

- AC-1 (FR-1): 操作ページが取得でき、開始・保存の一連の操作が成功して cookie が保存される。
- AC-2 (FR-2): 実行中に別の開始要求を送ると 409 になり、待機中はブラウザが起動されていない。
- AC-3 (FR-3): 保存の結果には、対象ドメインの cookie だけが Netscape 形式で含まれ、保存件数が返る。
- AC-4 (FR-4): 対象の cookie が0件の保存要求は 422 になり、ブラウザは終了せずに実行中のままである。
- AC-5 (FR-5): 保存の失敗・取り消し・時間切れ・起動失敗のいずれでも、ブラウザが終了して待機状態に戻る。
- AC-6 (FR-6): タッチ・マウス・キー・文字入力・戻る・再読み込みが、対応するブラウザ操作の列に変換される。
- AC-7 (FR-6): 表示領域の変更が全タブの画面サイズと画面配信に反映され、範囲外の値は上下限に収まる。
- AC-8 (FR-7): 元のタブを持つ新しいタブへ表示が切り替わり、表示中のタブが閉じると残りのタブへ戻る。
- AC-9 (FR-8): 起動引数がヘッドレスでなく、スマートフォン操作のときだけユーザーエージェントを持ち、言語を設定値に合わせる。
- AC-10 (FR-8): タイムゾーンが UTC のままの起動では、警告が出力される。
- AC-11 (FR-9): ブラウザの制御ポートの起動引数に外部向けのアドレス指定が含まれない。
- AC-12 (FR-10): プリセットは定義の開始 URL と対象ドメインで起動し、新しいサイトは保存に成功したときだけ履歴に加わる。
- AC-13 (FR-11): 履歴の削除で cookie も消え、プリセットと実行中のプロファイルの削除は拒否される。
- AC-14 (FR-12): クエリ付きで操作ページを開くと、プロファイルが選択され、未知のサイトでは開始 URL が入力欄に入る。
- AC-15 (FR-12): プロファイル一覧に各プロファイルの保存日時が含まれ、未保存は空になる。
- AC-16 (NFR-1): 時間切れを待つと、ブラウザが終了して待機状態に戻る。
- AC-17 (NFR-2): 保存の応答・プロファイル一覧・操作ページに、cookie の値が含まれない。
- AC-18 (NFR-3): 待機中はブラウザの生成が0回で、終了後は生成した全てが停止している。
